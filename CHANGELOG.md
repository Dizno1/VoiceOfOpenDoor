## 2026-08-05 (2)

- Hardening pass on Analyze, per Chap's review: `run_analysis()` called `analyze_file()` without a general exception handler. Since `analyze.py`'s `subprocess.run()` calls aren't guarded, a missing FFmpeg/FFprobe on PATH would raise an uncaught `FileNotFoundError` that crashes the whole Flask request - stopping every remaining file in a batch, not just the one that failed. Reproduced this for real by mocking `subprocess.run` to raise the exact exception, confirmed the crash happened on the un-hardened code, then fixed it: `run_analysis()` now catches `FileNotFoundError` (specific "run Setup" message), `PermissionError`, and any other exception, converting each to a structured failure instead of a crash.
- Verified the fix at both the function level and the full HTTP route level: simulated FFprobe going missing partway through a real 3-file batch request - confirmed a 200 response, the first file analyzed successfully, and the other two failed cleanly with a specific message, with the batch never stopping short.
