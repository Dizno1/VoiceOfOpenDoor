# Development Environment

## Reference Platform

Windows 11 is the first-class, reference platform for this repository. All setup scripts, installation documentation, and verification procedures should support Windows 11 as the primary path. Linux support may exist as a secondary/optional path but must not be presented as the default.

- Operating System: Windows 11
- Primary Browser: Google Chrome
- Primary Screen Reader: JAWS

## Verification Policy

Any claim that a tool "works" or is "installed" must specify where it was verified:

- **Verified on Dean's Windows 11 system** — confirmed working in the actual target environment. This is the only status that means the tool is ready for project use.
- **Verified in a temporary development/AI-assistant environment** — confirmed working in a sandbox used by an AI assistant during a session. This does not establish that the tool works on the target Windows system and must not be described as if it does.
- **Planned / unverified** — not yet installed or tested anywhere.

Every tool status in this repository (see `Tools/Audio Processing/README.md`) should use one of these three labels explicitly.
